## Общее описание

Начнём с обобщенного, `Realix` - гибридная ОС x86 с широкой кодовой базой на русском языке, имеющая свой MBR загрузчик с возможностью выбора режима работы процессора.

1. `Bootix (Stage 1)` - 512-байтовый MBR загрузчик, из-за своего ограничения, он выполняет минимальный функционал:
   - Установить стек, сегменты, сохранить загрузочный диск в BPB. (Bios Parameter Block, о нём будет далее)
   - Инициализировать драйвер диска.
   - Загрузить файл второго этапа загрузчика (Initrix) с минимальным функционалом в целях экономии места.
   - Передать управление ему, настроив стек и передав номер загрузочного диска.

2. `Initrix (Stage 2)` - логическое продолжение загрузчика, можете считать его "расширением" Bootix, выполняет следующее:
   - Оповещение о начале этапа инициализации. (Вывод текста на экран)
   - Инициализация критически важных драйверов. (На момент написания это FAT12 и BIOS Disk драйвер)
   - Установка IVT обработчиков некоторых (пока что) исключений и 0x80 (Syscall)
   - Получение информации о памяти. (Получение карты памяти, кол-во памяти)
   - Создания структуры о ПК - `PCINFO` (Будет дорабатываться)
   - Вывод загрузочного экрана.
   - Переход в Switcher.

3. `Switcher` - подмодуль Initrix, который выполняет интерактивный выбор ядра, задача одна, но она разделена на подзадачи:
   - Обеспечить таймер, по истечению которого, осуществляется загрузка 32-битного ядра
   - Обеспечить выбираемость между пунктами меню
   - Сделать дву функции: Загрузка 16-битного ядра, загрузка 32-битного ядра с переходом в Protected Mode
